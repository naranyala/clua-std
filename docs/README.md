# Documentation

`clua-std` is a small native standard library for Lua. The documentation is
split by the questions a contributor or user is likely to have:

- [Getting started](getting-started.md) — install prerequisites, build the
  module, run tests, and run the example.
- [API reference](api.md) — complete public Lua API and behavioral contracts.
- [Architecture](architecture.md) — Lua/C boundaries, source layout, and
  memory ownership.
- [Testing](testing.md) — test layers, coverage expectations, and known local
  environment limitations.
- [Build and portability](build-and-portability.md) — CMake, Lua ABI, module
  linking, and platform notes.
- [Extending the library](extending.md) — criteria and workflow for new APIs.
